# 기존 통합 PPT의 사용 범위

2026-09-07의 최신 통합 매뉴얼 v4(48장)를 보존했습니다. 초안 v1~v3과 렌더링·검사 중간 파일은 정리했습니다. 원본 생성 스크립트는 .codex-ppt-build/build_manual.mjs에 남겨두었습니다.

**최신 운영 기준은 [2026-09-09 점검 결과](../docs/08_프로젝트_점검결과.md)와 [일반 사용자 안내](../docs/07_일반사용자_보고서열람가이드.md)입니다.** v4는 수정 전 스냅샷이므로 아래 내용을 함께 확인하세요.

- 초기 스키마의 SSO 컬럼 누락과 재기동 시 권한 변경 SQL을 수정했습니다.
- 잘못된 Bearer가 다른 계정 쿠키로 인증되던 동작과 권한 화면 불일치를 수정했습니다.
- SSO 탭 토큰은 쿼리 문자열 대신 URL fragment로 전달합니다.
- 앱이 X-Forwarded-For를 직접 신뢰하지 않으며 기본 보안·캐시 헤더가 추가됐습니다.
- 보고서 삭제 시 의미 모델을 자동 삭제하지 않습니다.
- 백업 실행 파일 경로 설정, 실패 파일 정리, 수동 백업 보존을 수정했습니다. 실제 전체 DB 백업은 스키마 접근 권한 문제로 여전히 실패합니다.
- 회귀 테스트와 일반 사용자용 /help가 추가됐습니다.
- PPU/PP3 운영 용량 문제, HTTPS 설정, 실제 RLS·차트 렌더링·부하·복원 검증은 남아 있습니다.

PPT는 내부 전달용이며 Git 추적에서 제외됩니다. 수정된 최신 매뉴얼로 오인하여 단독 배포하지 마세요.
