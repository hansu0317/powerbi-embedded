일반 사용자 열람 안내

관리자 · 개발자

보고서 접근 관리

계정 생성, 보고서 허용, Power BI 운영 기반을 각각 준비합니다.

직원 온보딩

  1. 사용자 관리에서 활성 일반 계정을 만들고 부서를 입력합니다.
  2. SSO를 쓰면 Microsoft 계정을 포털 이메일에 연결합니다.
  3. 보고서 관리에서 개인 또는 부서에 열람권한을 부여합니다.
  4. 일반 계정으로 로그인하여 허용 보고서와 금지 보고서를 함께 확인합니다.

실제 열람 규칙

활성 계정과 활성 보고서에 대해, 개별 차단이 없고 본인 소유·포털 공용·개인 허용·부서 허용 중 하나이면 열람합니다. 관리자는 활성 보고서를 모두 봅니다.

폴더와 업로드 권한은 보고서 열람권한을 대신하지 않습니다. 공용 전환은 전 직원에게 영향을 줍니다.

운영 전제

PPU/PP3만으로 App-Owns-Data 운영 요건이 충족되지 않습니다. 지원 유료 용량, HTTPS, 유효한 백업과 복원, 민감 모델의 RLS를 확인하세요.

Microsoft 라이선스 조건 · Embedded RLS

현재 기능 범위

신규 PBIX 업로드는 비공개로 시작합니다. 콘텐츠 업데이트·내보내기·관리자 설정 핫 리로드는 제공하지 않습니다. 보고서 삭제는 Power BI에도 반영하며 의미 모델은 자동 삭제하지 않습니다.

행 수준 보안은 모델 RLS가 담당합니다. 부서 표시 필터는 사용자가 제거할 수 있는 화면 편의 기능입니다.
